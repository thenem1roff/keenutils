## KeenUtils Installer (Entware)

Интерактивный установщик программ для Keenetic с Entware.

Запуск в shell Entware от root через SSH/Telnet:

```sh
wget -O /tmp/keenutils-install.sh https://raw.githubusercontent.com/thenem1roff/keenutils/main/install && sh /tmp/keenutils-install.sh
```

Если установленный `wget` не поддерживает HTTPS, сначала установите его SSL-версию:

```sh
opkg update && opkg install ca-certificates wget-ssl
```

При первом запуске установщик сохранит себя в `/opt/bin/keenutils`, проверит файл и сразу откроет меню. В дальнейшем достаточно вводить `keenutils` в терминале Entware (или `/opt/bin/keenutils`, если `/opt/bin` отсутствует в `PATH`). Повторно скачивать скрипт по длинной ссылке не нужно.

Для обновления самого установщика выберите в главном меню **`88. Обновить KeenUtils`**. Новая версия скачивается из этого репозитория, проверяется и заменяет установленную с сохранением резервной копии `/opt/bin/keenutils.backup`. Если версия не изменилась, перезаписи нет. После успешного обновления по Enter запускается обновлённое меню.

Затем, если требовалось установить HTTPS-совместимый `wget`, повторите команду первичной установки. `curl` для первого запуска не требуется; установщик сам добавит его при необходимости для отдельных операций.

Не запускайте интерактивное меню через `curl | sh`: скрипт должен читать ответы с терминала.

Пункты: 1 nfqws, 2 nfqws2, 3 nfqws-web, 4 KeenKit, 5 HydraRoute Neo, 6 AWG Manager, 7 TorrServer (подменю), **88 обновление KeenUtils**, 99 список пользовательских приложений Entware, 00 выход.

- Сначала проверяются пакеты и ожидаемые файлы; nfqws и nfqws2 не устанавливаются поверх друг друга.
- Проверка пакетов использует `opkg list-installed`, учитывая статусы `install user installed` и `install ok installed`. Подтверждения принимают `y/n` на английской раскладке: `[Y/n]` — Enter = да, `[y/N]` — Enter = нет.
- Пункт 99 выводит только известные пользовательские приложения и отдельные установленные скрипты, скрывая системные библиотеки и зависимости. Историю установки `opkg` не позволяет установить гарантированно; список приложений можно расширять в `show_packages()`.
- Сторонние инсталляторы запускаются только после подтверждения; не вызывается общий `opkg upgrade`.
- Пункт `7. TorrServer` открывает отдельное подменю: `1` — установить через `opkg`, `2` — обновить (aarch64), `3` — установить/проверить watchdog, `4` — настроить кеш через API, `0` — назад. Эти операции независимы: установка TorrServer больше не запускает автоматически обновление, настройку кеша или watchdog. После любой операции Enter возвращает в подменю.
- Кеш создаётся в `/tmp/mnt/<том-с-Entware>/tscashe` только если накопитель проверен; иначе настройки не меняются.
- `UseDisk` и `TorrentsSavePath` меняются через локальный API `/settings`; исходный JSON сохраняется в `/opt/var/backups/keenutils` с правами 600. Скрипт проверяет том Entware через `/opt`, выводит диагностику `df -h` при неоднозначности, обрабатывает HTTP Basic Auth и подтверждает запись повторным чтением API. Останавливать процесс не нужно, однако изменение настроек вызывает переподключение торрент-сессий, поэтому не выполняйте его во время воспроизведения.
- Чтобы расширить меню, добавьте функцию `install_*`, строку в `menu()` и ветку в главном `case`.

Проверка расположения файлов и пакетов не гарантирует функциональную настройку каждой сторонней программы; сверяйтесь с требованиями выбранного проекта.

### Самостоятельные TorrServer-скрипты

- `torr_watchdog`: перед выполнением проверяет существующий watchdog, обе строки Cron, синтаксис и доступность команд. Если всё готово — выходит без изменений. Иначе через `opkg` ставит только недостающие зависимости (включая `curl`, `procps-ng-pgrep`, `psmisc`, `cron` при отсутствии), дополняет Cron без дублирования, не перезаписывает существующий файл watchdog и затем повторяет проверки.
- `torrserver`: перед обновлением проверяет команды и автоматически устанавливает отсутствующие зависимости Entware. Установленный бинарник и служба обязательны; скрипт не изменяет расписание Cron или watchdog.
- В обоих сценариях `opkg update` вызывается только когда требуется установить пакет. Общего `opkg upgrade` нет. Проверки на реальном роутере пока не выполнялись.

## Сторонние проекты

KeenUtils — независимый проект, не связанный с авторами перечисленных программ. Все права на сторонние программы принадлежат их правообладателям. Установка выполняется из официальных источников. Условия использования определяются лицензиями соответствующих проектов.

- [nfqws](https://github.com/nfqws/nfqws-keenetic)
- [nfqws2](https://github.com/nfqws/nfqws2-keenetic)
- [nfqws-web](https://github.com/nfqws/nfqws-keenetic-web)
- [KeenKit](https://github.com/spatiumstas/KeenKit)
- [HydraRoute Neo](https://github.com/Ground-Zerro/HydraRoute/tree/main/Neo)
- [AWG Manager](https://github.com/hoaxisr/awg-manager)
- [TorrServer](https://github.com/YouROK/TorrServer)

KeenUtils не является официальным установщиком перечисленных проектов. Ссылки ведут на их исходные репозитории; авторство и лицензии следует проверять в соответствующих проектах.
