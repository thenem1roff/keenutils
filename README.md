# KeenUtils

**Установщик и менеджер программ для роутеров Keenetic с Entware.**

KeenUtils объединяет популярные сетевые утилиты в одном консольном меню. Помогает устанавливать программы, запускать доступные меню управления, обновлять и удалять компоненты, не разыскивая каждый раз отдельные команды.

## Установка

Запустите в терминале Entware от пользователя `root` (через SSH):

```sh
opkg update && opkg install ca-certificates wget-ssl
wget -O /tmp/keenutils-install.sh https://raw.githubusercontent.com/thenem1roff/keenutils/main/install
sh /tmp/keenutils-install.sh
```

После установки откройте меню командой:

```sh
utils
```

Команда `keenutils` также поддерживается.

## Программы

| № | Программа | Для чего |
| :--: | --- | --- |
| 1 | **nfqws** | Обработка трафика и обход DPI-ограничений. |
| 2 | **nfqws2** | Новая версия инструментов обхода DPI. |
| 3 | **nfqws-web** | Веб-интерфейс для управления nfqws. |
| 4 | **nfqws-menu** | Выбор и настройка стратегий nfqws. |
| 5 | **KeenKit** | Набор инструментов для Keenetic в отдельном меню. |
| 6 | **HydraRoute Neo** | Маршрутизация трафика через выбранные подключения. |
| 7 | **AWG Manager** | Управление туннелями AmneziaWG. |
| 8 | **TorrServer** | Торрент-стриминг, обновление и обслуживание службы. |
| 9 | **Flashkeen** | Установка и запуск меню управления дисками и Entware. |

Пункт **8 → 1** устанавливает и запускает TorrServer, затем предлагает обновление, настройку watchdog и дискового кеша с ограничением скорости и 20 соединениями на торрент. Все три дополнительных действия можно пропустить; пункты 2–4 работают самостоятельно.

Пункт **9** устанавливает Flashkeen из официального проекта, если он отсутствует, и открывает его меню. После выхода управление возвращается в KeenUtils. Удаление доступно через **88 → Flashkeen**: удаляется сама программа и подтверждённые команды запуска; дисковые утилиты, KeenKit и резервные копии сохраняются.

## Дополнительные инструменты

| № | Действие |
| :--: | --- |
| **77** | Автоустановка выбранных программ по очереди. |
| **88** | Удаление программ и очистка их остатков с подтверждением. |
| **99** | Обновление KeenUtils. |
| **00** | Выход. |

В пункте **77** можно указать несколько номеров через пробел, например `2 3 4 7 8`. KeenUtils последовательно вызывает обычные установщики выбранных программ — со всеми их стандартными вопросами, но без дополнительных пауз между программами. Повторные номера пропускаются; если один установщик выдаст ошибку, очередь продолжится, а в конце покажет проблемные пункты. Для TorrServer вызывается **8 → 1**, а не его подменю. В режиме автоустановки **nfqws-menu, KeenKit и Flashkeen не открывают свои интерфейсы** после установки или при повторном выборе: KeenUtils устанавливает либо проверяет их и сразу переходит к следующей программе. При ручном выборе пункта меню запуск этих интерфейсов сохраняется. Штатные вопросы установщиков остаются.

В меню KeenUtils пустой **Enter** возвращает на предыдущий уровень или завершает работу. В меню сторонних программ действуют их собственные команды.
