## KeenUtils Installer (Entware)

Интерактивный установщик программ для Keenetic с Entware.

Установка в shell Entware от root через SSH/Telnet:
```sh
opkg update && opkg install ca-certificates wget-ssl
```
```sh
wget -O /tmp/keenutils-install.sh https://raw.githubusercontent.com/thenem1roff/keenutils/main/install && sh /tmp/keenutils-install.sh
```

**Повторный запуск:** введите `utils` или `keenutils` в терминале.

Во внутренних меню **самого KeenUtils** Enter без цифр выполняет действие пункта `0`: возврат назад, а в главном меню — выход. У стороннего KeenKit для выхода используется `00` (пустой Enter в KeenKit не закрывает меню).

### Главное меню

| Пункт | Программа | Назначение |
| --- | --- | --- |
| **1** | **nfqws** | Обход DPI-блокировок, первая версия. |
| **2** | **nfqws2** | Обход DPI-блокировок, вторая версия. |
| **3** | **nfqws-web** | Веб-интерфейс для управления nfqws/nfqws2. |
| **4** | **nfqws-menu** | Оригинальное меню выбора и установки стратегий обхода блокировок. |
| **5** | **KeenKit** | Установка и запуск оригинального меню KeenKit; выход через `00` возвращает в KeenUtils. |
| **6** | **HydraRoute Neo** | Маршрутизация выбранного трафика через нужные подключения и туннели. |
| **7** | **AWG Manager** | Установка и управление VPN-туннелями AmneziaWG. |
| **8** | **TorrServer** | Установка, обновление, watchdog и настройки кеша через отдельное подменю. |
| **77** | **Конвертер Flowseal → nfqws2** | Отдельный модуль: загрузка стратегий Flowseal и сохранение конвертированных конфигураций. На стадии разработки **не применяет** их к роутеру. |
| **88** | **Удаление программ** | Удалить установленную программу и отдельно очистить её остатки. |
| **99** | **Обновить KeenUtils** | Скачать новую версию самого меню из этого репозитория. |
| **00** | **Выход** | Закрыть меню. |

### Конвертер Flowseal (пункт 77)

Запускается из KeenUtils как отдельный локально сохраняемый модуль `/opt/bin/keenutils-flowseal`. При входе модуль скачивает только небольшой файл `flowseal.version`; если версия не изменилась, исполняет локальные файлы. При выпуске обновления загружает новую версию отдельно, проверяет синтаксис и только после успешной подготовки переключается на неё. Если GitHub недоступен, запускается уже сохранённая версия. После выбора `0` управление возвращается в главное меню KeenUtils без повторного запуска установщика.

Текущий **первый этап разработки**: выбор профиля из последнего официального ZIP-выпуска Flowseal, вопрос об игровых портах `[Y/n]` (Enter = Да), конвертация и автоматическое сохранение в `/opt/etc/keenutils/flowseal/strategies/`. Доступны просмотр и удаление ранее сохранённых стратегий. **Перенос штатных LIST/BIN, проверка совместимости с установленным nfqws2, применение к роутеру и откат пока не реализованы**. Установленные `nfqws2.conf`, списки и служба не изменяются.

Тестирование отдельной ветки без изменения установленного `utils`, список ограничений и структура файлов: [документация конвертера](docs/FLOWSEAL_DEV.md).

### Настройка кеша TorrServer (пункт 8 → 4)

Через API TorrServer выполняется настройка дискового кеша на накопителе с Entware и следующих параметров, соответствующих веб-интерфейсу:

- **Кеш:** 1024 МиБ (`CacheSize=1073741824` байт).
- **Кеш впереди воспроизводимого кадра:** 95% (`ReaderReadAHead=95`).
- **Буфер предзагрузки:** 5% (`PreloadCache=5`, около 51 МиБ).
- **Лимит загрузки:** 6250 КиБ/с (`DownloadRateLimit=6250`, TorrServer сам умножает значение на 1024 до байт/с).

Изменяются только эти четыре параметра, `UseDisk` и путь `TorrentsSavePath`; остальные настройки сохраняются. Перед записью KeenUtils делает резервную копию ответа API, а после записи проверяет все значения повторным чтением. Если значения уже соответствуют целевым, повторная запись не выполняется. При сохранении TorrServer может переподключить текущие торрент-сессии.

**Важно:** кеш 1024 МиБ требует достаточного свободного пространства на накопителе; на устройствах с ограниченными ресурсами учитывайте доступную память и нагрузку на накопитель.

### Удаление программ (пункт 88)

KeenUtils показывает только обнаруженные программы и оставшиеся файлы. Для каждой доступны: **1** — штатное удаление способом автора, **2** — очистка остаточных файлов, **3** — связанные программы, **4** — проверка состояния. Удаление и очистка остатков требуют отдельного подтверждения **`[Y/n]`**: **Enter подтверждает**, `n` отменяет. Защитные проверки сохранены; конфигурации и другие программы не удаляются автоматически. Для TorrServer отдельно отключается watchdog, а опасный полный очиститель HydraRoute не запускается.

**Самоудаление KeenUtils:** выберите KeenUtils в пункте 88 и подтвердите `[Y/n]` (Enter — согласие). Одной операцией удаляются только `/opt/bin/keenutils`, собственная ссылка `/opt/bin/utils` (только если она указывает на KeenUtils), резервная копия скрипта, собственный `sources.conf` и проверенный временный установщик (если есть). Пустые каталоги удаляются. Программы, Cron и резервные копии настроек TorrServer не затрагиваются. Общие журналы, история терминала и файловые снимки могут сохранять сведения о прежнем использовании.

## Сторонние проекты

KeenUtils — независимый проект, не связанный с авторами перечисленных программ. Все права на сторонние программы принадлежат их правообладателям. Установка выполняется из официальных источников. Условия использования определяются лицензиями соответствующих проектов.

- [nfqws](https://github.com/nfqws/nfqws-keenetic)
- [nfqws2](https://github.com/nfqws/nfqws2-keenetic)
- [nfqws-web](https://github.com/nfqws/nfqws-keenetic-web)
- [nfqws-menu](https://github.com/rndnaame/nfqws-menu)
- [KeenKit](https://github.com/spatiumstas/KeenKit)
- [HydraRoute Neo](https://github.com/Ground-Zerro/HydraRoute/tree/main/Neo)
- [AWG Manager](https://github.com/hoaxisr/awg-manager)
- [TorrServer](https://github.com/YouROK/TorrServer)

KeenUtils не является официальным установщиком перечисленных проектов. Ссылки ведут на их исходные репозитории; авторство и лицензии следует проверять в соответствующих проектах.
